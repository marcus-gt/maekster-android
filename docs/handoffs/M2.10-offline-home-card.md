## iOS (OfflineHomeCard)

A card leading offline Home: "Offline Mode" (manual) or "You're Offline" (no network), the number of
songs available offline ("Loading…" while counting, "No music saved on this device." when none), a
chevron into the songs when there are any, and "Turn Off Offline Mode" for manual offline mode.

## Implementation

- Android's offline Home appears only in manual offline mode (`SourceRepository.offline`), so the
  card is always the manual variant: "Offline mode" plus "Turn off offline mode"
  (`SourceRepository.setOfflineMode(false)`).
- `OfflineHomeCard` (ui/home): a rounded `surfaceContainerHigh` card with a cloud-off icon tile in the
  accent, title, status line (`home_offline_songs` plural / loading / nothing), and a chevron. The top
  row opens the downloaded Songs list (`OfflineListKind.Songs`) only when the count is above 0. A
  divider and a TextButton to turn offline mode off follow.
- `OfflineHomeScreen` shows it right after the title when `onTurnOffOffline` is set (so existing
  screenshot callers without it are unchanged); `HomeFeedContent` passes the count and the action.
- `DownloadDao.completedCount` → `LibraryRepository.downloadedSongCount` →
  `HomeViewModel.offlineSongCount` (null until counted) and `turnOffOfflineMode()`.
