# M2.8 Part K: Now Playing lyrics pane and current-line preview

**Status:** COMPLETE. Based on adfadd86; committed with this handoff.

## Implementation

- Now Playing bottom row: Lyrics | Queue | More. The Lyrics button (selected state, accent tint)
  swaps the cover for `LyricsPane`; the route forwards open/closed to `LyricsViewModel.setPaneOpen`.
- `LyricsPane`: Loading spinner; Missing ("No lyrics", or an offline "no saved lyrics" message);
  Failed with Try again; Instrumental; otherwise a LazyColumn of lines. Synced: current line full
  colour, others 40%, centred on the measured line centre (half-pane padding so first/last lines can
  centre); a manual drag stops following and shows Follow; tapping a timed line seeks via
  `LyricsTiming.seekPosition` (correction applied, clamped to duration). Plain: full colour, small top
  padding, no seek, no selected semantics. Fading top/bottom edges. Language menu when >1 language.
  "Lyrics from LRCLIB" credit when LRCLIB supplied them.
- `CurrentLyricLine` preview between the title row and the scrubber, fixed height, italic between
  note glyphs; tap opens the pane. Shown only while the preview setting is on.
- Back: AppRoot re-registers its own back callback last (it must beat the NavHost), so a screen-level
  BackHandler never ran on device. The pane state (`showingLyrics`) is hoisted to AppRoot;
  `overlayBack()` orders Queue > Lyrics > Now Playing > route. The pane closes when Now Playing does.
