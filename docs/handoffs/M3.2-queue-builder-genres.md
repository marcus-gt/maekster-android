# M3.2 Part E2b: Queue Builder main genres, sub-genres and the iOS-style card

**Status: DONE.** Committed on 17 Nov 2026, once the next session request allowed commits. Based on ccba65df (E2). This pulls the planned E4 taxonomy forward, because the requested UI needs main genres and
sub-genres. Requested by the user from iOS screenshots on 16 Nov 2026.

## Implementation

- `data/mix/DiscogsGenres.kt`: the Discogs genre/style list (15 genres, 400 styles, as listed by Essentia's
  `genre_discogs400` metadata). Discogs data is CC0, so it is written out as Kotlin with attribution; the iOS
  JSON file isn't copied.
- `GenreTaxonomy`: resolves library tags in iOS order: main name, Discogs style, alias, known sub-genre,
  "<style> <main>" spelling, keyword, else Other. Normalisation folds accents, reads "&" as "and", and keeps
  only letters and digits. The alias and keyword tables follow the iOS app's behaviour (MPL-2.0,
  GPL-compatible). The AudioMuse fallback is not ported.
- Engine: `QueueBuilderSelection(mains, tags, decades)`; `QueueBuilderIndex.columns` holds
  `QueueBuilderColumn(main, songCount, pills)`, biggest first with Other last.
  - Column counts are exact (`MixDao.songsWithGenres`, one indexed query per main genre).
  - Pill counts are summed per library spelling.
  - Matching expands picks into stored spellings, so it still uses the `song_genres(sourceId, genre)` index.
- Prefs: `queue_builder_mains_<id>` and `queue_builder_tags_<id>`. The flat `queue_builder_genres_<id>` key
  from E2 is removed on the next save (it was never released).
- View model: `focusedMain`, and the iOS tap rules:
  - `tapMainInCard`: pick and focus, then focus, then unpick with its sub-genres. It decides from the saved
    picks, so quick taps never act on stale state.
  - `togglePill`: on a wholly picked genre it narrows the pick to that sub-genre.
  - `toggleMain`: the page's column title.
- UI (`QueueBuilderUi.kt`):
  - **Card:** an open section like iOS, not a card. Title, chevron (opens the page), Reset, Play. Rows for main
    genres (chevron on the focused one), the focused genre's sub-genres, and decades. Summary such as
    "Contemporary Jazz and Fusion · 2020s and 1970s".
  - **Page (sheet):** genre columns, each a main-genre chip over its scrolling sub-genres, tinted by genre.
    Decades, length and Build as before.
  - `GenreTint` uses the iOS values (white-on-tint AA). Chips are `FilterChip`s.
  - Discover's list now pads each item, so chip and station rows scroll edge to edge.
- Moods: not shown. They need AudioMuse, which Android doesn't have yet; iOS also hides them without it.
