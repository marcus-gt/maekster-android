# M2.9: quick playlists, heart long-press menu and picker

**Status:** DONE in code and JVM tests; no emulator check yet. Settings page still to do.
Based on 2031a6d3 (data layer: `M2.9-quick-playlists-data.md`).

## Implementation

- `ui/components/FavoriteHeart.kt`: a shared song heart (`combinedClickable`, Role.Button, a
  "Quick playlists" long-click label for TalkBack). It replaces the row `FavoriteToggle` icon button
  in `SongsContent.kt` and the Now Playing heart (48dp target, 32dp icon, as before). Without a
  long-press handler, press-and-hold is an ordinary tap, as with the old IconButton.
- `LocalQuickPlaylists` (a static composition local of `((Song) -> Unit)?`): `AppRoot` provides it
  over the whole shell (NavHost, Now Playing, queue) unless offline mode is on. No callbacks are
  threaded through screens: every `SongRow` heart and the Now Playing heart get the long-press.
- `ui/playlist/QuickPlaylistSheets.kt`:
  - `QuickPlaylistMenuSheet`/`Route`: a bottom sheet with the song header, then "Add to <name>"
    for each quick playlist in order. While loading (null) no "Choose…" appears; with none it shows
    "Choose quick playlists…". It always ends with "Add to playlist…" (the full sheet).
  - `QuickPlaylistPickerSheet`/`Route`: the user's own playlists (the existing `destinations` query,
    owner-aware), ticked when quick and toggled on tap, plus a hint and Done. Each opening has its
    own ViewModel store (`PlaylistSheetScope`).
- `QuickPlaylistMenuViewModel` runs the add on the app `io` scope, so the menu closes at once (as on
  iOS) and a snackbar reports "Added to X" / "Already in X" / `playlistEditMessage(failure)`.
  `QuickPlaylistPickerViewModel` waits for the owner before paging, like the add sheet.
- `MenuItem` in `ItemContextMenu.kt` is now internal, so the quick menu uses the song menu's row style.
- `AppRoot`: `quickPlaylistSong`/`quickPlaylistPicker` state, sheets beside `AddToPlaylistRoute`;
  "Add to playlist…" hands over to the full sheet; opening Now Playing from the notification
  closes them like the other sheets. New strings are English only.
