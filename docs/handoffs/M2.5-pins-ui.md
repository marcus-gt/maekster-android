**Status:** complete (12 Nov 2026). M2.5 still has pin-management work.

## Implemented
- Shared menus offer Pin to Home / Unpin from Home for albums, playlists and artists; no song pins.
- PinMenuRoute/ViewModel observes the exact source/kind/id, keyed to avoid old item state.
  Writes use the target's source, not whichever server becomes active afterward.
- Home starts with a paged mixed Pinned carousel; settings can hide/reorder the section.
  Existing saved Home layouts normalize the new section into first place.
- Room joins resolve metadata locally, preserving type and pin insertion order.
  Missing refs stay stored but hidden until mirrored again; no network metadata calls.
- Taps load one local entity and use existing navigation callbacks; long press opens its existing menu.
  Async target resolution checks the active source before invoking callbacks.
- PagingSource + cached Paging flow keep reads paged; keys include source/type/id.
- No schema/dependency change. Pinned has no grid or pin-order editor yet.
  Offline Home still uses downloaded shelves; pin actions themselves work locally.
