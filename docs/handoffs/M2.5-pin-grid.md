# M2.5 Part G: Paged pin grid

**Status:** complete (12 Nov 2026). M2.5 still has pin ordering and offline Pinned.

## Implemented
- Pinned joins the shelves that support the carousel/grid choice (`HomeShelf.supportsGrid`); the existing inline
  selector in Application > Home sections, Save/Reset and the DataStore codec cover it with no new UI or key.
- The grid is not a FlowRow: `pinnedGrid` emits a header and one outer `LazyColumn` item per row, reading
  `LazyPagingItems` by index, so a long pin list stays paged and only nearby rows compose. Unloaded slots draw a
  132dp spacer. Columns fit the width (`pinGridColumns`: 132dp tiles, 8dp gaps, 16dp side padding).
- Carousel and grid share `PinnedTile` (artist circle, album/playlist rounded cover, taps and long presses).
- No schema, dependency, networking or playback change.

## Key files
HomeLayout.kt, HomeScreen.kt (BoxWithConstraints around the Home list), PinnedHomeShelf.kt; tests:
PinnedGridTest, UserPreferencesTest.
