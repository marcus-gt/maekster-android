# M3.3 D3a: Similar Artists local resolution and wiring

**Status: DONE (repository/wiring only).** Clean starting tree at 890b52e1.

## Implemented

- SimilarArtistsRepository resolves cached candidates against the requested source's mirror.
- Match priority: exact server id; unique case-insensitive MBID; unique exact name with
  SQLite NOCASE (ASCII case folding only). Name matches with conflicting known MBIDs
  stay external. Unmatched/ambiguous recommendations keep their remote metadata.
- Removes the seed and duplicate recommendations resolving to the same local artist.
- Reads re-resolve current mirrored rows, so later sync changes update local links.
  Queries return at most one id match or two MBID/name matches; no whole-table loads.
- Explicit refresh uses active-source + offline/connectivity guards through the cache,
  and returns no result if the source changed. Ordinary reads never call a provider.
- Singleton cache/repository in Koin; connectivity/offline uses the existing shared
  mixDownloadedOnly predicate. No screens call either API yet.
- SourceRepository builds the requested source's provider with its credentials and fixed
  origin-scoped custom headers, not the current source's mutable shared headers.
  Offline/missing/needs-sign-in configurations return no provider.
- No schema, dependencies, UI or privacy-policy changes.
