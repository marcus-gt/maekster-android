# M2.5 Part A: Your playlists first on Home

**Status:** complete (12 Nov 2026). Implemented and verified by Claude Code; committed on its own (see Git).
First part of M2.5 Home parity.

## What was built

- A "Your playlists" shelf leads Home (online), as on iOS. It shows up to 10 playlists, most recently changed first,
  falling back to the creation date when the server sends no change date (iOS does the same).
- Each card is a 200dp cover with the name, "Updated <relative date>" (omitted when there is no change date) and
  "N songs", like the iOS `TopPickCard` (250pt; smaller here so the next card peeks in). A tap opens the playlist and
  a long press opens the playlist menu.
- "More" opens the Library Playlists list. Home stays the selected tab, because the nearest tab root in the back stack
  decides. The list keeps its own saved sort rather than forcing "Updated".
- A library with only playlists now shows Home instead of the empty "Sync" state.
- Offline Home is unchanged: it already has a downloaded-playlists row.

## Key files and decisions

- `LibraryDao.recentlyChangedPlaylists`: `ORDER BY CASE WHEN changed > 0 THEN changed ELSE created END DESC, name, id`.
  Playlists are few per server, so the expression has no index.
- `HomeFeed.yourPlaylists`, `buildHomeFeed(playlists = …)` (a defaulted parameter, not gated on play data),
  `HomeViewModel.feed` combines the new flow.
- `HomeScreen`: `yourPlaylistsRow` and `RecentPlaylistCard`, new `onPlaylistClick`/`onPlaylistsMore`, and the
  `yourPlaylists` test tag. Not added to the `HomeSection` enum, because its "More" is not a Home list.
- `ui/components/PlaylistUpdated.kt` (`playlistUpdatedText`) is now shared by Home and the playlist page (moved from
  `PlaylistDetailScreen`). String `home_section_your_playlists`.
- No schema or dependency change.

## Verification

- `RecentlyChangedPlaylistsDaoTest`: order by change, the created fallback, the name tie-break, the limit and source

- `HomeYourPlaylistsTest`: shelf, updated and song-count lines, no "Updated" line without a date, tap and More
  callbacks; a playlists-only feed is not the empty state.
- Final: ktlintFormat, assembleDebug, testDebugUnitTest (1,210 tests, 0 failures), ktlintCheck, lintDebug.
- Pixel 9 API 37 with the real Navidrome mirror: Home opens with Your playlists ("Discover – backlog", "Discover – this
  month", "Updated 4 days ago", "50 songs"). More opened Playlists with Home still selected, and a card opened the
  playlist.

## Not verified / limits

- API 35, TalkBack, 2× font. Screenshot tests were not re-recorded or reviewed for the new shelf.
- A server whose playlists have neither a change nor a creation date sorts them by name.
