# M3.2 Part D4a: persisted autoplay control

**Status: DONE.** Based on 5e927e5a. Started by an earlier session (handoff left IN PROGRESS with the code
written but unverified); this session verified, finished and committed it.

## Implementation

- `UserPreferences.autoplaySimilar()` / `setAutoplaySimilar()` in DataStore (`autoplay_similar`), off by default.
- `PlaybackController` takes `autoplayPreference: Flow<Boolean>?`: init collects it (distinct) into
  `setAutoplaySimilar`, and `restore()` reads it first under `startLock`. If disabled after the restored
  window loads, it truncates the unplayed generated tail (current song/time and history kept) and refreshes.
- Koin passes `UserPreferences.autoplaySimilar()` to the controller and `UserPreferences` to `DiscoverViewModel`.
- Discover: "Autoplay similar" row (whole-row `toggleable`, `Role.Switch`, visual `Switch` with
  `onCheckedChange = null`) between Smart Shuffle and Stations, with a disclosure text (server online,
  downloads offline, paused with repeat/shuffle). Visible offline too. The list has test tag `discoverList`.
- No schema, dependency or toolchain changes. No provenance labels yet (D4b).
