# M3.5 A1: AudioMuse mood-score client

**Status: DONE (unwired client).** Base: 48f937cd; existing roadmap holds preserved.

## Implemented

- AudioMuseClient.moodScores interface; independent OkHttp transport for external/get_score?id=….
- Keeps configured reverse-proxy path; HTTP(S) only, no URL credentials/query/fragment.
- Only AudioMuse bearer token, branded User-Agent and Accept header; redirects disabled.
- Cancellation cancels the call; 120-second call/read timeout. Distinct HTTP failure categories,
  response bodies omitted from exceptions. Bad JSON/field types fail rather than returning empty success.
- Parses optional other_features and mood_vector into named scores and descending style labels.
  Unlike the iOS reference, ignores nonfinite/out-of-range values and empty labels.
- No wiring: no requests during browsing, no settings, persisted token, Room cache, UI or dependencies.
- Reference AudioMuseClient.swift and AudioMuseClientTests.swift read for semantics; no source copied.
