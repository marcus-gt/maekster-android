# M2.7 Part F: Unshuffled Clear upcoming repository operation

**Status:** complete (12 Nov 2026), based on clean a915c19b.

## Implemented
- QueueRepository.clearUpcoming(snapshot, currentPosition) trims an unshuffled combined queue
  to history plus the current track, including the correct retained part of the manual block.
- Uses entry lengths and reference ranges only; never resolves a song or expands a queue.
- Preserves existing range offsets, duplicates, repeat mode and current cursor/time.
- Queue entries, manual entries and cursor are written in one immediate Room transaction.
- Returns false for invalid positions and at the end. Rejects shuffled snapshots before writing.
- No schema, dependency, playback-controller or UI changes.

## Key files
- data/repo/QueueRepository.kt: clearUpcoming and bounded prefixEntries helper.
- test/data/repo/QueueRepositoryTest.kt: five new regression tests.
