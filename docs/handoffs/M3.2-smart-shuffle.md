## iOS reference (LibraryService.smartShuffleQueue, PlayerService.playSmartShuffle)

- iOS mixes three sources about equally:
  - Favourites: starred songs, plus 2 random starred albums and 2 starred artists.
  - Recent taste: the artists (3) and genres (2) of recent plays.
  - Rediscovery: random songs.
- `blendSmartShuffle` deals from each source in turn, each shuffled. It skips the last 50 played songs,
  allows at most 3 per artist, gives a dry source's turns to the others, and if everything was excluded
  allows recent plays back.
- The target is 50 songs, and offline uses the same sources limited to downloads.

## Implementation

- `data/db/MixDao.kt`: bounded random reads, each with `LIMIT` (pool 200) and an optional filter to
  completed downloads:
  - `recentPlays`: from `play_events` (M3.1 A), with the artist and primary genre from `song_genres`;
  - `starredSongs`, `starredAlbumIds`, `starredArtistIds`;
  - `songsOfAlbums`, `songsOfArtists`, `songsOfGenres`, `randomSongs`.
- `data/mix/SmartShuffle.kt`: `build(sourceId, downloadedOnly, targetSize = 50)` gathers the three pools
  from the mirror. Unlike iOS, it makes no server calls even online, because Android has the full mirror
  (D9). `blend` ports iOS's algorithm one for one, with an injectable `Random`.
- `PlaybackController.playMix(sourceId, songIds, collection)`: one song entry per pick (bounded by the
  mix), shuffle off. `start` now accepts an explicit `QueueCollection` label; `PendingPlay` carries it
  through a cold connect.
- `QueueCollection.SmartShuffle` (kind null, so it never matches a kind) gives Now Playing the title
  "Smart Shuffle".
- `playback/SmartShufflePlayer.kt`: `play(): Boolean` (false means nothing to play) for the Discover UI.
  Koin builds it with `downloadedOnly = offline mode || no network`.

## Verification

- `SmartShuffleTest` (6):
  - the blend deals in turn, caps each artist, skips recent plays, hands dry turns on, and a tiny library
    still plays;
  - build: favourites, recent taste and rediscovery all appear, and the song just played is left out;
  - offline uses only completed downloads, and an empty library gives an empty mix.
- `SmartShufflePlayerTest` (2): no server or an empty library gives false; offline starts only downloads.
- `PlaybackControllerTest` (+1): the mix plays in its own order with shuffle off, titled "Smart Shuffle".

  controller test. Both restored.

  installs, the app starts, the saved queue restores through the changed `start` path, and nothing
  crashes.

  that class passes 5/5 on its own. ktlintFormat fixed an import order and a `when` block's formatting;
  after that, ktlintCheck, lintDebug and assembleDebug pass.
