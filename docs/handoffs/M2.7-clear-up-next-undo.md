# M2.7 Part C: Undo clearing Up next

**Status:** complete (12 Nov 2026), based on clean c332443b.

## Implemented
- The existing manual Up next clear button offers "Up next cleared" with snackbar Undo.
- PlaybackController captures queue references/ranges, cursor, shuffle seed, manual block,
  anchor and playback position; it reuses the existing one-step Undo path.
- Clearing a currently playing block preserves pause/play intent instead of always autoplaying.
- Undo restores the removed block and shuffle. If the context track is still playing, it
  keeps that track's current position; if clearing replaced the playing block track, it
  restores that track's saved position. Position handling also covers the offline reload path.
- No whole song queue is materialized, and no schema or dependency changes are needed.
- Existing single-step Undo semantics remain: a later edit replaces the prior Undo.
