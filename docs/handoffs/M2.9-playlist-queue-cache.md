**Status:** COMPLETE; committed with this handoff.
Based on f57d514b.

## Scope / implementation

- Fixes the queue-cache issue noted in M2.9-delete-playlist.md.
- PlaylistRepository takes a libraryChanged callback. Koin wires the app's existing singleton
  QueueRepository.invalidateLibraryCache, the same operation SyncManager uses.
- All playlist mirror writes go through mirror/removeMirror, calling the callback only after
  Room succeeds: create readback, edit readback, conflict refresh, delete and not-found removal.
- Covers deletion even if the afterServerDelete download-cleanup hook throws.
- Failed server writes without a mirror change do not invalidate.
- This clears queue length/key/order caches and changes the queue version. Subsequent snapshots
  resolve fresh data; no queue/table is materialized and no active player window is replaced.
- No schema, dependency, UI or playback-controller change.
