# M3.2 Part D1: persisted extension boundary

**Status: DONE (storage only).** Based on 123e3efe; working tree initially clean.

## Implementation

- Room schema 58 adds nullable playback_cursor.extensionStart through a hand-written migration.
  Existing cursors retain their position, saved song, label and modes; the boundary starts null.
- Coordinate: queue_entries.position of the first generated context reference, not a flattened song
  index or up-next position. Reference coordinates avoid shifts when an album's song count changes.
- QueueRepository.extensionStart reads the persisted marker. Ordinary cursor, position and mode writes
  retain it through copy; replacing the queue clears it so a new context cannot inherit an old tail.
- No production path creates a non-null boundary yet. No autoplay toggle, generation, labels, append,
  truncation or behavior changes to normal playback in this subtask.
