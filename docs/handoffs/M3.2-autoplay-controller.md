**Status: DONE (controller API; no visible control yet).** Based on bded01fe; tree initially clean.

## Implementation

- PlaybackController.setAutoplaySimilar(Boolean): in-memory opt-in, false by default.
  False cancels work and trims the unplayed generated suffix under startLock, keeping current
  song/time and history. Repeated false can clean an existing boundary.
- refresh schedules coordinator attempts only while playWhenReady, enabled, repeat/shuffle off
  and <=15 songs remain. One attempt per queue-version/position/playback-intent key prevents
  repeated empty/error calls on ordinary refreshes. New track/queue/intent can retry.
- Generation runs outside startLock. AutoplayRefill accepts an optional commit callback;
  controller commits under startLock after rechecking intent, enablement, current position,
  active source and modes. Repository retains its stale-context checks.
- After append/truncate, controller refreshes snapshot/layout and rebuilds only the bounded player
  window without restarting the current item. Existing manual context edits retain D2 promotion policy.
- Disable, stop, seek, repeat/shuffle changes and offline/network transitions cancel pending work.
  Source/queue/position changes also invalidate commit via source, version and intent checks.
- Repeat/shuffle entry trims the generated tail before queue mode/order changes.
- Koin supplies one lazily created coordinator per controller using InstantMix and the shared DAO.
  No coordinator requests while disabled. Offline OR unavailable network restricts candidates to downloads.
- No dependencies/schema changes. No persisted preference, visible toggle or Similar to … labels yet.
