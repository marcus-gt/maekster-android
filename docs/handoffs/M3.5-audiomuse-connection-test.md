## Plan

1. ViewModel `test(url, token, keepToken)`: normalize the URL (Invalid on failure); token as Save does it
   (Keep saved token only at the same normalized URL, else error); inject a client factory
   `(AudioMuseConnection) -> AudioMuseClient` (default OkHttp) and an offline flow.
2. Run `warmup()` then `search(<fixed English test query, e.g. a mood query>, 5)`. Result states:
   Connected(count), Unauthorized, NotAudioMuse (404/invalid JSON), Unreachable (IOException/timeout),
   Failed. Never log the token or exception messages.
3. Separate test state from the save form; clear it when URL/token/keep-token changes or after Save/Remove.
   One action at a time (busy disables Test, Save and Remove). Cancel with the dialog's ViewModelStore.
4. Dialog: "Test connection" button next to Save; result row with icon + text (success in the theme's
   positive colour, errors in error colour); offline: button disabled with a short reason.
5. Strings: English only (values/strings.xml); in-app text says maekster in lowercase if it appears.
6. PRIVACY.md: the test sends one search text to the configured AudioMuse host only.
