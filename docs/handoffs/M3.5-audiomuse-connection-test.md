## Implemented

- `data/audiomuse/AudioMuseConnectionTester.kt`: warmup + one search (fixed English query, limit 5) with a
  20 s timeout. `AudioMuseTestResult`: Connected(matches), Unauthorized (401/403), NotAudioMuse (404/400 or
  a non-JSON / wrong-shape reply), Unreachable (transport failure or timeout), Failed (503/other HTTP).
  No exception text is surfaced. The JSONException is looked for along the whole cause chain, because
  coroutines' stack-trace recovery (assertions on, as in tests) wraps the client exception once more.
- `AudioMuseSettingsViewModel.test(url, token, keepToken)`: normalizes like Save; kept token only at the same
  normalized URL (else Invalid, no request); typed token trimmed, control characters rejected, blank means
  none. No request offline (offline mode or no network, same flow pattern as Discover). Result lives in
  `AudioMuseForm.test`; `testing` + `busy` block Test, Save and Remove. `inputsChanged()` cancels a running test
  and clears a stale result/error; Save and Remove replace the form, so results also clear there.
- Dialog: "Test connection" outlined button (shows "Testing…" and a spinner), offline reason text, result row
  with check / error icon (primary vs error colour). Every URL, token or keep-token edit calls `inputsChanged`.
- Koin passes the offline flow and `AudioMuseConnectionTester()::test`. PRIVACY.md describes the test request.
