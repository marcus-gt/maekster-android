# M2.8 Part H: lyrics preference persistence

**Status:** COMPLETE. Based on 1e3d9c8c; committed with this handoff.

## Implementation

- UserPreferences exposes one atomic LyricsPreferences Flow: source Auto by default, LRCLIB
  opt-in off, current-line preview on, timing correction zero and clamped to ±3000ms.
- Dedicated DataStore keys: lyrics_source, lyrics_lrclib_allowed, lyrics_current_line,
  lyrics_offset_ms. No Room/schema/dependency changes.
- Selecting LRCLIB without permission stores Auto and cannot grant permission. Disabling it
  atomically resets LRCLIB-only selection to Auto, retaining preview/correction and Server choices.
- Unknown source names recover to Auto. Out-of-range stored offsets are clamped when read too.
- Key files: LyricsPreferences.kt, UserPreferences.kt, LyricsPreferencesTest.kt.
