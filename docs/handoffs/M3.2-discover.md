# M3.2 Part C2: Discover tab

**Status: DONE.** Based on 0decff3d. Auto-extend and Queue Builder remain M3.2 D/E.

## Implementation

- Added Discover as the third tab (Home, Library, Discover, Search), using the existing saved
  nested-graph navigation and Settings access.
- DiscoverRoute/DiscoverScreen with a Smart Shuffle card and horizontal artist Stations shelf.
  Uses the existing ArtistIcon artwork and Material/maekster theme.
- MixDao.stationArtists observes at most 12 credited artists from the active source, favorites
  first, then recently played, then alphabetical. This is a bounded local shelf, not a network lookup.
  Empty mirror explains that library sync is needed.
- DiscoverViewModel observes source, offline preference and network availability. Offline hides stations
  and explains downloaded-only Smart Shuffle. Mixes run through the existing players/controller.
  Busy disables overlapping actions and shows progress; empty/error results use snackbars.
- SmartShufflePlayer rechecks the active source after building, as InstantMixPlayer already does,
  so switching servers during preparation does not start the old source's queue.
- No dependencies, schema or build configuration changed.
