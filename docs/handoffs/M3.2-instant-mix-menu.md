## Implementation

- Shared ItemContextMenu offers Instant Mix for songs/albums and Start station for artists.
  Playlists have no mix action. These work anywhere the shared menu is used, including Now Playing.
- AppRoot passes the action through PinMenuRoute to a Koin MixMenuViewModel scoped to the shell.
  Work survives menu dismissal; repeated requests while preparing are ignored.
- Snackbar messages explain preparation, empty results (downloads needed offline) and unexpected failure.
  Cancellation propagates. Existing engine handles server/cache/local fallback.
- InstantMixPlayer accepts an expected source ID and checks the active source again after building;
  a menu from another server or a switch during preparation cannot replace playback.
- No dependency, schema or build configuration changes.
