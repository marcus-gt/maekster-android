# M2.8 Part A: lyrics model and LRC parser

**Status:** COMPLETE. Based on 5c19650f; committed with this handoff.

## Implementation

- Added plain Kotlin Lyrics/LyricsLine values under data/lyrics; no Android dependencies.
- LrcParser handles repeated leading timestamps, 1–3 fractional digits (dot or colon), signed
  provider offset kept separately, enhanced word tags, BOM/Unicode and CR/LF/CRLF.
- Sorts by timestamp stably, retaining same-time source order and duplicates.
- Ignores metadata, invalid times and empty timed text; null when nothing usable remains.
- Only leading timing tags are parsed; bracketed timestamps within lyric text stay text.
- Read iOS source/tests for behavior; Kotlin implementation and fixture text written independently.
