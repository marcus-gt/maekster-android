# M2.8 Part G: language selection and lyric timing

**Status:** COMPLETE. Based on 60b20e58; committed with this handoff.

## Implementation

- LyricsSelection normalizes xxx/und, JDK ISO-3 terminology codes and BCP47 tags while retaining
  script/region choices. Explicit language wins (synced within it); otherwise prefer locale timing,
  any timing, locale plain, then first. Matching script is preferred within a locale's language.
- LyricsTiming precomputes a sorted cue timeline and index lookup. Current line uses binary search;
  duplicate timestamps choose the last line. Plain/instrumental/invalid times cannot seek.
- One effective timestamp drives highlighting and tap-to-seek: start - provider offset + correction.
  Positive provider offset=earlier; positive listener correction=later. Seek clamps to playable range.
- Exact BigInteger arithmetic only during construction, then clamped Long cues, prevents hostile
  offsets overflowing or changing sign. No allocations/arithmetic expansion during each lookup.
- Key files: LyricsSelection.kt, LyricsTiming.kt and their pure unit tests.
