# M3.5 C3: local AudioMuse track resolution

**Status: DONE (local resolver; UI/actions still unwired).** Clean start at c39afddb.

## Implemented

- AudioMuseTrackResolver / AudioMuseTrackDao verify IDs against the source-local mirror. Supplied
  metadata must agree with an existing ID; colliding IDs with contradictory tags use metadata fallback.
  Internal fp_ IDs are always resolved by metadata, even if a local ID happens to collide.
- Metadata fallback requires unique normalized title plus artist/album when supplied. Unicode NFKD,
  accent marks, case, punctuation and whitespace are normalized off-main. Album participates in the key.
- Conservative difference from iOS: no arbitrary ID tiebreak or containment-only/live/remaster guessing.
  Artistless metadata qualifies only when its title/optional album uniquely identifies a local song.
- Preserve input order and duplicate occurrences. Explicit unresolved indices and allUnresolved distinguish
  unavailable results from a genuinely empty search. Future path UI can reject incomplete endpoints.
- Direct-ID batches use primary-key lookups. Fallback scans lightweight projections in keyset pages of
  500 on Default; at most 500 requested results and per-descriptor ambiguity counters remain in memory.
  This is O(library size) for a metadata-fallback batch; normalized indexing is a later profiling option.
- Completed-download-only queries offline. Active source/effective offline changes cancel results.
  Selected rows are re-read before return; no match/miss cache survives a batch or library update.
- No network dependency, Koin/UI wiring, schema change, dependencies or playback changes.
- Read-only iOS SubsonicTrackResolver, TrackMatcher, MoodTrackProviders inspected; no source copied.
