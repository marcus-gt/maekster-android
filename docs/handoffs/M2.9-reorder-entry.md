## Scope and implementation

- PlaylistRepository.moveEntry moves the occurrence at a raw mirror position to its final index.
- Checks the song still occupies that position, then uses the existing reorder fresh-server check.
  Stale mirror/menu or changed server order refreshes the mirror and reports Changed without writing.
- Uses playlistEntrySongIds, retaining duplicates and entries without a library song row.
- Invalid destinations are rejected. Server-first replacement and transactional readback remain unchanged.
- No UI, schema, DI or dependency change. This is the bounded repository prerequisite for reorder UI.
