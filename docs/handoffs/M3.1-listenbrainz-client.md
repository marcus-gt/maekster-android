# M3.1 Part B: ListenBrainz client

**Status:** DONE. Not wired into the app yet; Part C does that. Based on 5f9aa363 (Part A:

## iOS reference

`ListenBrainzClient.swift`, `LBSubmitListensDTO.swift` and `ListenBrainzError.swift`:
- `GET {root}/1/validate-token` with `Authorization: Token …`. A 200 response gives `valid` and
  `user_name`; a 401 means an invalid token, not an error.
- `POST {root}/1/submit-listens` with `listen_type` `playing_now` (no `listened_at`), `single` or
  `import` (the offline queue). `additional_info` carries `duration_ms`, plus `submission_client` and
  `media_player`, both set to the brand name.
- Transient failures are network errors, 429 and 5xx. 401 is unauthorized; other statuses are permanent.

## Implementation

`data/listenbrainz/`:
- `ListenBrainzApi.kt`:
  - Types: `ListenTrack`, `Listen` (epoch seconds), `TokenValidation`.
  - `ListenBrainzException` with a `transient` flag. Subclasses: Network, RateLimited(retryAfterSeconds),
    Unauthorized, Http(status), InvalidAddress, Decoding.
  - Interface and constants: the `ListenBrainzApi` interface, `DEFAULT_ROOT` and
    `MAX_LISTENS_PER_REQUEST = 1000`.
  - Messages never include the token or the username.
- `OkHttpListenBrainzApi.kt`:
  - Built on OkHttp and `org.json` (no new dependencies).
  - The token goes only in the Authorization header; `UserAgent.value` is sent; `MaeksterBrand.NAME` is
    the client name.
  - `endpoint(root, path)` keeps a path in the root, for a self-hosted server under a subpath.
  - `import` refuses more than 1,000 listens and skips an empty list.
