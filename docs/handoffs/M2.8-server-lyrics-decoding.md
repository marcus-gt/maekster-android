# M2.8 Part B: server lyrics decoding

**Status:** COMPLETE. Based on 1eff635e; committed with this handoff.

## Implementation

- SubsonicXml.lyrics uses the shared SAX response/error/XXE protections.
- Decodes structured multilingual timed/plain entries. Normalizes xxx/missing to und and lowercases
  other language tags. Keeps provider offset separately; timed entries sort stably.
- Skips invalid/missing/negative/overflowing synced starts and empty text. Unsynced entries retain
  source order without misleading seek timestamps. Empty entries produce no lyrics.
- Classic getLyrics text becomes LRC if usable, otherwise plain lines. Entity/CDATA/fragmented
  text is preserved. No network, cache, UI, schema or dependency changes yet.
- Key files: SubsonicXml.kt, SubsonicLyricsXmlTest.kt.
