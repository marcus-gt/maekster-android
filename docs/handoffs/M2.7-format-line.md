# M2.7 Part B: Player format and source line

**Status:** complete (12 Nov 2026), based on clean 294e882f.

## Implemented
- Now Playing shows source and format below the scrubber/time labels.
- Streaming / Transcoding / Downloaded comes from the loaded media item's metadata.
  A download takes precedence even when streaming quality requests transcoding.
- Origin is exposed by PlayerHandle and PlaybackState and clears with the current item.
  Metadata survives session transport even when localConfiguration is absent.
- Codec, bitrate and sample rate come from the selected decoder track (Part A).
  Unknown/invalid fields are omitted. Sample rates show exact kHz (44.1, 96).
- No synced source-file quality is used as a fallback: a transcoded download can differ.
  Bit depth is omitted because AudioEncoding does not expose actual decoded bit depth.
- Unknown origin hides the line. Known origin with no encoding shows only the source label.
- No dependency, schema, queue or playback-policy change.
