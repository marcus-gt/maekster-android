## Differences from iOS (deliberate)

- No tag-based fallback without AudioMuse (roadmap: mood controls only when AudioMuse is usable).
- All resolved matches (≤200) are queued at once instead of 50 + refill; afterwards the existing autoplay
  continues from the current song (only with autoplay on) instead of from the top-10 seeds.
- No Room cache of radio results: a radio is fresh per start and hidden offline (iOS also hides it).
