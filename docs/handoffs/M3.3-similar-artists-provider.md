# M3.3 D1: Similar Artists provider

**Status: DONE (provider foundation only).** Started from clean 1b2f5f82.

## Implemented

- SimilarArtists interface and SimilarArtist result, separate from mirrored Artist rows.
- SubsonicSimilarArtists uses getArtistInfo2 with id, bounded count and includeNotPresent=true.
- Preserves server ordering, name, cover-art reference and MusicBrainz id.
- Missing/blank/-1 server ids become null (external candidates). Library membership must
  be resolved against the local mirror by the next layer, never inferred from a name here.
- Blank names, the seed artist and duplicate candidate keys are skipped; at most 50 results
  are retained, even when a server ignores count. Empty id/nonpositive count makes no request.
- Uses existing authenticated SubsonicClient, IO dispatcher, 15-second timeout, SAX parsing
  and error handling. Failed/invalid responses propagate, allowing a future cache to retain data.
- No UI/DI wiring, cache, new browsing requests, third-party calls, dependencies or schema changes.
