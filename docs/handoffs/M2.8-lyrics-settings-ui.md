# M2.8 Part I: lyrics settings and privacy disclosure

**Status:** COMPLETE. Based on e2e45f1f; committed with this handoff.

## Implementation

- Settings > Playback gains a Lyrics row (value: current source) opening `LyricsSettingsDialog`:
  source radio (Auto, Server, LRCLIB), Allow LRCLIB lookups switch with the privacy disclosure
  directly below it, Show current line in player, timing correction slider (±3000 ms, 100 ms
  steps, written on release) with Reset.
- LRCLIB source is disabled until lookups are allowed; the Part H preference transition resets
  an LRCLIB-only choice to Auto when permission is withdrawn.
- `SettingsViewModel.lyrics` reads `UserPreferences.lyrics()`; four setters write through it.
- Dialog content scrolls so every control stays reachable at 2× font.
- Key files: `ui/settings/LyricsSettingsDialog.kt`, `SettingsScreen.kt`, `SettingsViewModel.kt`,
  `strings.xml`, `LyricsSettingsDialogTest.kt`, `SettingsScreenTest.kt`.
