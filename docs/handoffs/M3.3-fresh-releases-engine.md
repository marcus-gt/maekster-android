# M3.3 Part B: fresh-releases engine

**Status: DONE (engine only; nothing calls `refresh` yet, so no network use).** Based on a8b4b9bb (Part A).

## Behaviour (iOS `LibraryNewReleasesService` and `NewReleaseWatchlist`)

- **Who is followed:** album artists with at least one album in this server's mirror.
  - Skipped: special-purpose names (Various Artists, VA, Unknown…) and MusicBrainz' special-purpose ids.
  - Only real UUIDs count as MusicBrainz ids; a Discogs integer means "unknown", so the name is looked up.
- **Window and filtering:** the last 90 days up to today (UTC).
  - Kept: released (an unknown date counts as released), credited to a followed artist, not owned.
  - "Owned" means the normalised title matches an album by any credited followed artist.
  - One entry per title and date; newest first; at most 500.
- **Two passes:**
  1. Artists with known ids, from tags or the name cache, are searched and published first.
  2. Up to 120 name lookups per refresh, then their searches, then a second publish.
- **Name cache:** hits are kept; misses are retried after 30 days; failed lookups aren't stored, so they're
  tried again.
- **Refresh policy:** due after 20 hours; not retried within 15 minutes of an attempt (`isStale`,
  `refreshIfStale`). One refresh at a time (`tryLock`).
- **Failures:** a failed search throws and keeps the previous result.
- **Server switch:** publishing checks `isCurrent()`, so a switched server stores nothing.

## Android-specific

- Bounded memory: the mirror is read 25 album artists at a time by keyset (`watchArtists` with `ar.id > :afterId`),
  plus their album titles (`ownedAlbums`). Neither table is loaded whole; each page becomes one MusicBrainz search.
- Since one page's search can return a release owned under an artist on another page, the owned set is global and
  applied at publish time.
- **Storage, schema 59** (`MIGRATION_58_59`, hand-written; all three tables cascade with their server):
  - `fresh_releases` (`sourceId`, `id`, `position`, title, credit name, partial date, type label).
  - `fresh_release_state` (`refreshedAt`, `attemptedAt`).
  - `musicbrainz_names` (normalised name, nullable id, `triedAt`).
  - `FreshReleaseDao.publish` replaces a server's feed in one transaction.
- `MusicBrainz.ARTISTS_PER_SEARCH` (25) moved onto the interface.
- Koin: one `MusicBrainzRateLimiter`, `MusicBrainz` (OkHttp) and `FreshReleases` singles.
