## Implementation

- `data/mix/SimilarSongs.kt`: seed types (song, album, artist) and injectable similarity interface.
- `SubsonicSimilarSongs`: explicit server action; getSimilarSongs for songs/albums,
  getSimilarSongs2 for artists, using the configured source client and a 15-second timeout.
- Room schema 57: `similar_songs` caches ranked IDs per source/seed, replaced transactionally;
  source deletion cascades. Metadata and playback still resolve from the local mirror.
- `InstantMix`: 50-song target, song seed first, server relevance order for songs,
  artist interleaving for album/artist seeds, cap of four per artist in server ordering.
  On request failure use the cache; without similar results use the seed artist/genres,
  then Smart Shuffle. Offline never asks the server and limits all choices to downloads.
  Cancellation propagates. Cache has no expiry; online actions refresh it.
- `InstantMixPlayer`: artist seed implements a station; starts through PlaybackController.playMix,
  with the Instant Mix collection title and shuffle off. Shared offline/network policy with Smart Shuffle.
- No dependencies or build configuration changed.
