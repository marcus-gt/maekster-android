# M2.9 Part E: remove a song from a playlist

**Status:** COMPLETE. Based on 4de849c5; committed with this handoff.

Scope: "Remove from playlist" in a song's menu on its playlist page (iOS: SongRow context menu,
destructive, no confirmation, disabled offline, error toast on failure). Only for the user's own
playlists (same owner rule as the add sheet) and not in offline mode. Rename/delete and drag
reorder are later parts.

## Implementation

- `LibraryDao.playlistEntrySongIds`: entry order without the songs join, so indices are server
  positions even when the mirror lacks a song row (QueueDao's joined query would misalign).
- `PlaylistRepository.removeEntry(position, songId)`: if the mirror no longer has songId at that
  position, refresh and throw Changed (no write); then the existing `remove` server-order check.
- `MenuTarget.Song.playlistPosition` (set by PlaylistDetailScreen from `item.position`) and
  `ItemActions.removeFromPlaylist`; the menu item shows only when both are present.
- `PlaylistDetailViewModel.canRemove` via `canRemoveSongs(playlist, offline, user)`; Koin passes
  PlaylistRepository, `SourceRepository::username` and `showMessage`. `removeFromPlaylist` shows
  "Removed from <name>" (Android snackbar; iOS removes silently and optimistically) or the shared
  failure message. No optimistic row removal: the row goes when the mirror refresh lands.
- `ui/playlist/PlaylistEditMessages.kt`: `playlistEditMessage`, moved from AddToPlaylistViewModel.
