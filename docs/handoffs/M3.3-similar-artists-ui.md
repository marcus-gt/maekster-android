**Status: DONE (Subsonic-backed UI).** Clean start at f7c9825d.

## Implemented

- Shared SimilarArtistsSection and SimilarArtistsViewModel on artist and album routes.
  Stateless detail screens accept optional composable section slots.
- Shelves sit after discography/appearances or album tracks. First section composition
  reads cached recommendations only. Find similar artists explicitly refreshes online.
- Offline cached results remain visible; no refresh button. Empty offline sections hide.
  Empty online results leave the action available, with a generic unavailable message after checking.
- Local cards display mirrored names and navigate with resolved library ids.
  External cards open a validated MusicBrainz UUID page or an encoded artist-name search.
  No server credentials/headers are involved in browser links; no portrait/image requests.
- Source/connectivity changes clear state, cancel pending work and reload the cache;
  generation guards prevent old results publishing. Busy refresh taps coalesce.
- Album uses its primary artist id; pages without one have no section.
- DI resolves the parameterized ViewModel. DI test cancels and joins its scope before teardown.
- No schema/dependency changes.
