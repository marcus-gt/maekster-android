# M2.7 Part G: Unshuffled Clear upcoming action

**Status:** complete (12 Nov 2026), based on clean 27f82111.

## Implemented
- Queue options offers Clear upcoming for unshuffled queues with tracks after the cursor.
  Availability is derived from the full controller snapshot, not loaded UI rows.
- Controller serializes the edit, invokes Part F, captures one-step Undo and rebuilds
  only the bounded window around the unchanged playing track.
- Playback source, position and play/pause intent remain intact.
- Undo restores context/manual ranges and playback position using the shared cleared-queue
  Undo type (renamed from ClearedBlockUndo).
- A rejected/no-op edit returns false and does not offer a misleading snackbar Undo.
- Manual Clear up next remains available via Queue options, including while shuffled.
- No schema or dependency changes. Shuffled Clear upcoming is explicitly guarded.
