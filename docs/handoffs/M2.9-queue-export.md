# M2.9: bounded queue export for playlist saving

**Status:** COMPLETE for the local export prerequisite; server saving and UI remain open.
Based on 3991c197.

## Implementation

- QueueRepository.playlistBatches(snapshot, sourceId, batchSize) is a cold Flow of song-ID lists.
  Batch size 1..100; next batch is resolved only after collector consumption of the previous one.
- Uses range() over the captured combined playback order: shuffle, retained shuffle prefixes,
  up-next insertion, reference ranges and duplicate occurrences use existing queue resolution.
- Validates entry and resolved-song source IDs; mixed sources cannot be sent to one server playlist.
- Checks queueVersion before reading/emitting and after final consumption. Queue edits/library
  invalidation abort; cursor-only movement does not alter the captured order.
- An incomplete/misaligned resolution fails before emitting the affected batch, rather than silently
  dropping songs. Empty captured queue emits nothing.
- Memory is bounded by references already in QueueSnapshot and at most 100 resolved tracks/IDs per
  batch. No new table, dependency, UI or server action.

## Limits / next

This is the local export prerequisite, not a Save queue UI. Next implement a bounded server-save
operation and retained draft, then the dialog/menu. Do not collect this Flow into a whole-queue list.
Existing PlaylistCreation.songIds is a List and cannot simply be fed the entire export.

Version checks detect repository notifications, not a transactional library snapshot. Earlier batches
may already be consumed when a later batch fails; the saver must retain partial creation state and
never report completion on an aborted export. Playback consuming up-next can invalidate the export.
Unrelated library invalidations are conservative too: the saver must avoid invalidating its own
export by mirroring destination writes between batches (use writer-level batching and mirror after
completion, or explicitly design staging). Server readback/retry must also remain bounded.
No new exception UI yet; saver must translate IllegalArgumentException/IllegalStateException.
