# M3.2 Part D4b: "Similar to …" provenance labels

**Status: DONE.** Based on 1fc1d868 (D4a); tree initially clean.

## Implementation

- `QueueSnapshot.extensionStart` (read from `playback_cursor` in `snapshot()`) and
  `QueueSnapshot.isGenerated(position)`: true only for a context song whose top-level entry position is at or
  after the boundary. Up next and shuffled queues never count as generated.
- `PlaybackState.generated` for the current song, set in `refresh()` from the cached snapshot (no extra DB read).
- `QueueCollection.endless` (Smart Shuffle, Instant Mix, which includes artist stations), following iOS
  `QueueSource.isEndless`: those keep their own name when extended.
- `PlaybackController.sourceHeading(context, resources, generated)` returns `SourceHeading(title, similar)`.
  If the song is generated and the source isn't endless, the title is "Similar to <name>" (`queue_similar_to`).
  A generated song with no stored source label gets no heading, so the UI falls back as before.
  `sourceTitle` delegates to it (new `generated` parameter, default false).
- Queue header: "Similar to X" on its own instead of "Playing from Similar to X" (`QueueScreen.contextSimilar`).
  Now Playing shows it as the title line under "NOW PLAYING: <kind>". Both re-query when `generated` changes.
- Only the current song's header is labelled, like iOS `PlayerState.queueSourceLabel`. No per-row labels.
- No schema, dependency or toolchain changes.

## Known issues / not verified

- Now Playing's small kind line reads "NOW PLAYING: SONG" for an appended song, because extension entries are
  song entries. It is accurate but plain; a dedicated kind label could follow if wanted.
- Turning autoplay off while on an album song also removes appended songs that had already been played
  (D2 truncation keeps only the current song and what comes before it in the original queue).
- Not checked on a device: offline transition, disabling during generation, a process restart with an
  appended tail, and repeat/shuffle (covered by Robolectric tests only).
