# M2.8 Part C: server lyrics provider

**Status:** COMPLETE. Based on 7012dfce; committed with this handoff.

## Implementation

- LyricsProvider is a suspend fetch(Song) seam returning language variants.
- SubsonicLyricsProvider is bound to a source ID and the existing authenticated SubsonicClient;
  rejects songs from another source before requesting anything. No DI/UI wiring yet.
- Prefers getLyricsBySongId; nonempty structured/plain response wins. Empty results fall back
  to classic getLyrics with trimmed artist/title; missing metadata suppresses that lookup.
- Fallback allowed for HTTP 404/405/501 and Subsonic 0/20/30/70. Code 0 is generic: some servers
  use it for unsupported calls; try the read-only classic endpoint, propagating its failure.
- Auth/permission, HTTP server errors, malformed XML and transport failures propagate. Classic
  not-found returns empty. Checks cancellation before/after each request, preventing a fallback
  after cancellation. Each blocking request has a 5-second timeout on Dispatchers.IO.
- Key files: LyricsProvider.kt, SubsonicLyricsProvider.kt, SubsonicLyricsProviderTest.kt.
