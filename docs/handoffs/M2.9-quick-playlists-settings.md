## Implementation

- Settings > Application: a "Quick playlists" row (bolt icon, after Home sections) when a server
  is active. It opens `QuickPlaylistsSettingsRoute` → `QuickPlaylistsDialog`, an AlertDialog like
  Home sections that follows the iOS QuickPlaylistsSettingsView:
  - hint; "No quick playlists yet." when empty;
  - rows in the chosen order, each with a 48dp drag handle (Move up/down custom accessibility
    actions, like Home sections) and a remove button ("Remove <name>");
  - "Choose playlists…" opens the existing picker sheet over the dialog; disabled in offline mode,
    as iOS disables it while offline;
  - the "Also add to Favorites" switch (DataStore, default on); then Done.
- While dragging, the order is kept in a local draft and stored once via `QuickPlaylistRepository
  .setOrder` (new; a transactional replace) when the drag stops. Accessibility moves store immediately.
- `QuickPlaylistsSettingsViewModel(sourceId, quick, preferences)` in Koin. `SettingsScreen` keeps
  its existing parameter list: the dialog resolves its own ViewModel.
- iOS also reconciles names with the server list on open; Android needs nothing, because names come
  from the mirror and deleted playlists drop out of the join.
