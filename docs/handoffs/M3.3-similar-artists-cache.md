**Status: DONE (cache/orchestration foundation).** Clean start at bfb73574.

## Implemented

- Schema 60: similar_artists_cache keyed by sourceId/artistId, cascading on source deletion.
  Hand-written MIGRATION_59_60 and exported schema; versioned JSON payload plus fetchedAt.
- SimilarArtistsCache.read is Room-only, including stale/offline results.
- Explicit refreshIfStale has a 24-hour TTL, including successful empty responses.
  Corrupt payloads are ignored and can be refreshed. Clock rollback makes a row stale.
- Provider factory receives the source id. canRequest must reflect active source and
  connectivity; checked before construction, before request and before publication.
- Failed refreshes retain the previous result and timestamp. Cancellation propagates.
- Mutex serializes refreshes; concurrent same-seed requests reuse the first fresh result.
  Responses and decoded payloads are capped at 50 artists.
- No DI/UI wiring or new network calls. No dependencies or build configuration changes.
