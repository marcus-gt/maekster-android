# M2.8 Part E: cache-first lyrics orchestration

**Status:** COMPLETE. Based on 48129eb0; committed with this handoff.

## Implementation

- LyricsRepository takes explicit source, offline and LRCLIB opt-in inputs. ProvidedLyrics retains
  provider provenance for attribution and language choice. No UI/DI wiring or external client yet.
- Server/LRCLIB modes consult only their own cache/provider. Disabled LRCLIB is excluded even
  when cached; explicit LRCLIB mode returns empty when disabled (UI must show its enable action).
- Auto prefers synced server, then permitted synced LRCLIB over server plain, retaining server
  plain as fallback. Server errors may fall back externally only with opt-in. External errors keep
  server plain if available. Cancellation always propagates, including during plain fallback.
- Cache first, offline misses never network, positive results persist with injected timestamp.
  Empty results are not cached permanently. No TTL or refresh action yet.
- Key files: LyricsRepository.kt and LyricsRepositoryTest.kt.
